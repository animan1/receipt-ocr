# Receipt OCR

Python library scaffold with a hello-world function and no runtime dependencies.

Use Python 3.12 and `uv`. Run `make setup` to install the locked development dependencies, then `make check` to check formatting, lint, types, tests, and coverage. Run `make build` to produce a source distribution and wheel. Bare `make` lists the available commands.

GitHub Actions runs the same checks on Linux and macOS.
